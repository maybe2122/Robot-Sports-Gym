# Robot Sports Gym v0.3.0

**Five sports, one benchmark protocol — a benchmark candidate, not yet a leaderboard.**

## Highlights

- **All five canonical single-shot tasks run.** `table-tennis-return` (mocap fixture, Franka Panda, Unitree G1 fixed-base and free-standing, with state and vision tracks), `tennis-return-v0`, and three new launch tasks: `badminton-serve-v0`, `football-kick-v0`, `basketball-shoot-v0`. Each has a versioned Gymnasium environment, a simulation-verified shot bank with 100 test episodes per level, frozen L0–L5 criteria and a rule judge (ITTF/ITF/BWF/IFAB/FIBA).
- **Learned baselines (M5).** PPO over a three-parameter swing primitive, 5 seeds per task, trained on the train split and scored on the test split through the same report path as every other baseline, next to a random-primitive floor. Weights, training curves, wall time and hardware are committed.
- **Isaac Lab, for real.** The table-tennis Isaac Lab environment ran on Isaac Sim 5.0 / Isaac Lab 0.46.2 on CPU and GPU PhysX and was compared shot by shot with MuJoCo: ball flight agrees to 3.5 mm, judge verdicts to 99%; post-bounce contact differs by ~5 cm (the M4 calibration target). The run found and fixed a doubled aerodynamic force.
- **Auditable results.** `scripts/audit_submission.py` recomputes every verdict and metric of a result package from its raw episodes, checks each level contains exactly the bank's shots, verifies digests and weight hashes, and can replay the package.
- **Versioned schemas, license manifest, API reference, lock file.** Every published file format has a JSON Schema; `THIRD_PARTY_LICENSES.md` lists every asset, dataset and weight file; `docs/API.md`; `uv.lock` reproduces the environment (tests pass on Python 3.10 and 3.13 from a clean sync).

## Baselines at a glance (test split)

See [`reports/cross-task-summary.md`](../../reports/cross-task-summary.md) for every task × level × controller.

Learned baselines — PPO over a three-parameter swing primitive, mean of 5 seeds (untrained primitive / random primitive in brackets):

| Task | L2 success | L3 placement | L4 worst bucket | L5 worst bucket |
|---|---|---|---|---|
| Table tennis (fixture, `return-v1`) | **98%** (0% / 13%) | **25%** (0% / 4%) | **87%** (0% / 7%) | **42%** (14% / 9%) |
| Tennis | 60% (58% / 22%) | 2% (2% / 0%) | 21% (22% / 5%) | 0% (0% / 0%) |
| Badminton serve | 100% (100% / 62%) | **36%** (19% / 8%) | 100% (100% / 36%) | 80% (79% / 36%) |
| Football kick | 100% (100% / 78%) | 9% (**49%** / 9%) | 100% (100% / 56%) | 27% (21% / 15%) |
| Basketball shoot | **36%** (2% / 4%) | **9%** (0% / 2%) | 2% (4% / 0%) | 7% (0% / 0%) |

Learning clearly helps table tennis, basketball and badminton placement; on tennis it only matches the primitive's mid-range prior, and on football it *hurts* placement (PPO converges to a mean that trades target precision for goal probability under its own exploration noise). Details and the reasoning are in [`docs/LEARNED_BASELINES.md`](../LEARNED_BASELINES.md).

## Fixes that move previously published numbers

- The mocap fixture path never applied the L5 perturbations its manifests declared. Tennis `scripted` L5 falls from 32% to 0%; L1–L4 are unchanged.
- `robustness_gap` no longer counts L1 (whose return rate is zero by construction) in its in-distribution numerator. Stored reports were recomputed from their level breakdowns.
- An IK stall exit cut the intercept baseline's control latency from 0.94 to 0.35 ms (mean); the Panda/G1 tables were regenerated — every primary metric unchanged.

## Physics fixes found while adding sports

- Badminton: shuttle drag is now evaluated at the centre of pressure from current state — the old model had no pitch damping and read one-step-stale state, so tumbling shuttles diverged numerically. The benchmark scene uses a 0.5 ms step and interpolates the fixture pose across each control period.
- Football: moving balls start in pure rolling; the benchmark scene uses PGS, because MuJoCo's Newton solver resolved the ball-on-pitch plus boot contact pair into direction-dependent 4–7° errors. Goal posts and crossbar now match IFAB inner dimensions.
- L3 targets were never given to policies; they now are (`info["target"]`, `TargetObservation`, `reset(target=...)`).

## Not in this release

Every shot bank is `experimental` and no leaderboard is open. Tennis, badminton, football and basketball are mocap-fixture tasks, not robot tasks; the biped asset football needs is missing; robots have no Isaac adapter yet; no real-world calibration data (M4); no DOI and no external reproduction yet (M6). See [`docs/TODO.md`](../TODO.md).

## Install

```bash
git clone https://github.com/maybe2122/Robot-Sports-Gym && cd Robot-Sports-Gym
uv sync --extra test            # add --extra train for the learned baselines
uv run multisport-benchmark --sport football --level L3 --split test --controller scripted
```
